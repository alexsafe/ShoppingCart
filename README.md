# Shopping Cart with Sales Tax

## Problem Statement

You're building a simple shopping cart system for an online store. Each item in the cart has a name, price, and quantity. Your task is to calculate the total cost of the cart including sales tax.

## Requirements

1. Define a structure to represent each item in the cart.
2. Items should fall within distinct categories.
3. Each category should have a different discount percentage.
4. Apply a fixed sales tax rate (e.g., 8.5%) to the subtotal.
5. Output:
   - Subtotal (before tax)
   - Sales tax amount
   - Total cost (after tax)

## Constraints

- Prices are in dollars and cents (e.g., 19.99).
- Quantities are whole numbers.
- Sales tax is applied to the subtotal only.
- Have at least 3 distinct categories.
- Discounts should be calculated before taxes.

## What we are looking for

- Adherence to SOLID principles
- Automated testing
- Working solution

## What we are not looking for

- Beautiful UI
- User input (the item list can be hard coded)
